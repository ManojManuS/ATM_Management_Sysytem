# 🏦 ATM Management System in Java

A simple, console-based ATM Management System developed using Java. It allows users to perform basic banking operations through a menu-driven interface.

## ✨ Features

- Account authentication using account number and PIN.
- Check account balance.
- Deposit money.
- Withdraw money.
- Change PIN.
- Validate transaction amounts.
- Simple menu-driven interface.

## 🛠️ Technologies Used

- Java
- Scanner Class
- Object-Oriented Programming (OOP)
- Conditional Statements
- Loops and Switch Statements

## 💻 Prerequisites

- Java Development Kit (JDK) installed.
- A code editor or terminal.

## 🚀 How to Run

**Step 1: Compile the program**

```bash
javac ATMManagementSystem.java
```

**Step 2: Run the program**

```bash
java ATMManagementSystem
```
